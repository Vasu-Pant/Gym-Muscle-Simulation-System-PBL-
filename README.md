# Gym-Muscle-Simulation-System-PBL-
This repositry contains the codebase of Gym Muscle Simulation System which is a topic done by Vasu Pant, Ayush Barthwal, Ayush Rathi and Arpit Kathait as a project for Project based learning. This project offers a software where the user can store their workouts throughtout the week or any given time and get a detailed report on how much each muscle is activated and the total volume done by that muscle at the end of the given time.
